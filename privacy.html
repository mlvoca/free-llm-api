4. Cookies

This website uses no cookies, no analytics, no tracking pixels and no social media plugins, and it loads nothing from other servers. The only information stored on your device is one entry in your browser's local storage, so that the cookie notice is shown only once:

Name: mlvoca-cookie-notice
Content: the date the notice was shown
Storage period: until you clear your browser data
Shared with: no one; it never leaves your browser

This entry is strictly necessary to show the notice as intended and therefore needs no consent (article 22.2 of Spanish Law 34/2002, LSSI-CE). The "Copy" buttons only write to your clipboard when you click them.

5. Using the API

When you send a request to https://mlvoca.com/api/generate, the server processes your IP address, the time of the request, the request content (prompt and parameters) and the generated response.

  • Purpose: generating the response, enforcing the rate limit and protecting the service against abuse.
  • Legal basis: article 6(1)(b) GDPR (providing the service you request) and article 6(1)(f) GDPR (our legitimate interest in a secure and fairly shared service).
  • Prompts and responses are processed in memory to generate the answer and are not stored.
  • Rate limiting keeps your IP address in the server's memory for a few minutes.
  • Server logs: the web server records the IP address, time, requested path, status code and user agent of each request. These logs are kept for up to 14 days and then deleted automatically.
  • Hosting: the API server runs in a data center in Germany, operated by STRATO GmbH (Otto-Ostrowski-Straße 7, 10249 Berlin, Germany) as our processor.

Please do not send personal or confidential data in prompts.
