Quickstart

One endpoint, based on the Ollama generate API. Send a JSON body with a model and a prompt.

POST https://mlvoca.com/api/generate

Single response

curl
curl -X POST https://mlvoca.com/api/generate -d '{
  "model": "tinyllama",
  "prompt": "Why is the sky blue?",
  "stream": false
}'
Python
import requests

r = requests.post(
    "https://mlvoca.com/api/generate",
    json={"model": "tinyllama", "prompt": "Why is the sky blue?", "stream": False},
    timeout=300,
)
if r.status_code == 429:
    raise SystemExit("Rate limit reached: wait a minute and try again.")
r.raise_for_status()
print(r.json()["response"])

Streaming

Without "stream": false, the answer arrives word by word as newline-delimited JSON.

curl
curl -X POST https://mlvoca.com/api/generate -d '{
  "model": "deepseek-r1:1.5b",
  "prompt": "Why is the sky blue?"
}'
Python
import json
import requests

with requests.post(
    "https://mlvoca.com/api/generate",
    json={"model": "deepseek-r1:1.5b", "prompt": "Why is the sky blue?"},
    stream=True,
    timeout=300,
) as r:
    r.raise_for_status()
    for line in r.iter_lines():
        if line:
            print(json.loads(line)["response"], end="", flush=True)

Models

Small open models that run on modest hardware. Set the model field to one of these values.

Modelmodel valueGood for
TinyLlama (1.1B)tinyllamaFast, short answers and experiments
DeepSeek R1 (1.5B)deepseek-r1:1.5bStep-by-step reasoning. The answer starts with the model's reasoning between <think> and </think>.

Parameters

The request body is a JSON object with these fields.

FieldDescription
modelrequiredThe model to use: "tinyllama" or "deepseek-r1:1.5b".
promptrequiredThe input text to generate a response for.
streamfalse returns one JSON object instead of a stream. Default: true.
format"json" or a JSON schema, to get structured output.
systemSystem message that overrides the model's default.
optionsModel parameters such as temperature or num_predict.
suffixText that comes after the model's response.
templateCustom prompt template.
rawtrue sends the prompt without any template formatting.

Rate limits and fair use

The API runs on shared, limited hardware. Limits keep it available for everyone.

5 / minute

Requests per IP address

Short bursts of a few requests are allowed. Above the limit, the API answers 429 Too Many Requests: wait a moment and retry.

5 minutes

Maximum response time

A single response that takes longer is cut off. Use streaming for long answers, or limit the length with options.num_predict.

Non-commercial

Research, teaching and learning

Commercial use is not allowed. For research projects or any other larger use, please get in touch first.

Responses can be slower during busy times. Please don't send personal or confidential data in prompts.

Status codes

CodeMeaning
200Success.
400The request body is not valid JSON or a field has a wrong value.
404Unknown model: check the model value.
429Rate limit reached: wait a moment and retry.
502 / 504The model server is busy or temporarily unavailable: try again later.
